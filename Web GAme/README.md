# 🎮 Hangman Game

A classic Hangman word-guessing game built with **HTML, CSS, and JavaScript** — coded back in **2017** as a fun side project.

---

## 🧠 About the Game

Guess the hidden word one letter at a time. Each wrong guess brings the Hangman one step closer to doom! Your goal is to guess the word before the hangman is complete.

---

## ✨ Features

- ✅ Random word selection from a pre-defined list  
- ✅ Visual Hangman image updates with each wrong guess  
- ✅ Tracks and displays wrong guesses  
- ✅ Sound effects for wins, losses, and incorrect guesses  
- ✅ Custom font and background design for a chalkboard/classroom vibe  
- ✅ Game-over and victory alerts

## 🚀 How to Run Locally

1. Clone or download the repo  
2. Open `index.html` in your browser  
3. Play!

```bash
git clone https://github.com/yourusername/hangman-game.git
cd hangman-game
open index.html
```
